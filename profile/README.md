# Dojo NG

Framework-agnostic web components, built on Lit. The `dj-*` elements run in
React, Vue, Angular, Svelte, or in plain HTML with no framework. Dojo NG is the
successor to the Dojo 2 widget set, rebuilt as standards-based custom elements.
BSD-3-Clause.

## These repositories are mirrors

Development happens in Mercurial on
[foss.heptapod.net/dojo-ng](https://foss.heptapod.net/dojo-ng). The copies here
are read-only, pushed from Heptapod after every change.

Clone from GitHub to read or build the code, the same as any other repository:

    git clone https://github.com/dojo-ng/components

Nothing pushes back the other way, so a pull request opened here can't be
merged, and issues and merge requests go to Heptapod. To send a change, work
from the Mercurial repository:

    hg clone https://foss.heptapod.net/dojo-ng/components

Branches keep their Mercurial names, so the default branch reads
`branch/default`.

## Where to start

Docs, the component reference, and getting started: [dojo-ng.com](https://dojo-ng.com/).
The playground: [play.dojo-ng.com](https://play.dojo-ng.com/).
On npm, each component is its own package under the `@dojo-ng` scope.
